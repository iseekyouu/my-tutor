# Словарик — тренажёр слов

Весь стек на Bun: сервер `Bun.serve`, база `bun:sqlite` (файл `data.db`),
фронтенд на React собирает и отдаёт сам Bun, без Vite.

## Запуск

```bash
bun install
bun run dev      # разработка с hot reload: http://localhost:3000
bun run start    # продакшен-режим
bun test         # тесты базы и проверки ответов
bun run typecheck
```

Переменные окружения:
- `PORT` — порт (по умолчанию 3000)
- `DB_PATH` — путь к файлу базы (по умолчанию `data.db` в папке проекта)
- `GEMINI_API_KEY` — ключ Gemini для кнопки ✨ (бесплатный, https://aistudio.google.com/apikey).
  Без ключа всё работает, кроме ✨. Локально: `GEMINI_API_KEY=... bun --hot server/index.ts`
- `GEMINI_MODEL` — модель (по умолчанию `gemini-flash-lite-latest`)

Сервер слушает `0.0.0.0`, поэтому с телефона в той же Wi-Fi сети он открывается
по `http://<IP-компьютера>:3000`.

Бэкап словаря: скопировать `data.db` (при остановленном сервере) или
сделать «Экспорт» в интерфейсе.

## Как пользоваться

1. Добавьте слова: слово, русский перевод и/или английский (нужен хотя бы один перевод).
   Много слов сразу — «Импорт»: JSON из «Экспорта» или текстовый файл, по строке
   `слово - перевод - english` (`слово - перевод` без английского, `слово - - english` без русского).
   Несколько вариантов перевода — через запятую: `дом, здание`.
   Дубли не добавляются: одинаковым считается слово без учёта регистра, пробелов и
   черты среднего тона (`nāam` = `naam`; `náam` и `nàam` — разные). При вводе
   появится предупреждение, а при импорте дубли пропускаются
   (с итогом «добавлено N, пропущено дублей M»).
2. Под полем слова — таблица гласных транслитерации (a e i o u) с пятью тонами:
   средний, низкий, нисходящий, высокий, восходящий — `ā à â á ǎ`.
   При проверке ответа `ā` и `a` (средний тон с чертой и без) считаются одинаковыми.
   Кнопка вставляет букву в позицию курсора: `n` + `á` + `am` → `náam`.
   Кнопка «тон» прячет таблицу. У полей с русским переводом таблицы нет.
3. Теги — группы слов («еда», «урок 3»). В поле «Теги» Enter или запятая превращают
   набранное в тег, подсказки — из уже существующих. После добавления слова теги в форме
   остаются (удобно вводить группу подряд).
   Обучение по тегам: над кнопкой «Начать обучение» — ряд тегов. Можно отметить несколько —
   тренируются слова с любым из отмеченных тегов; «Все» снимает выбор. Список словаря
   показывает те же слова. Клик по тегу у слова оставляет только этот тег.
4. «Начать обучение» — слова идут в случайном порядке. Enter — проверить / дальше.
   Засчитывается любой перевод — русский или английский.
   «Показать ответ» засчитывается как ошибка.
   Если ответ сочтён неверным, но по смыслу он верный (опечатка, другая формулировка),
   кнопка «Засчитать» рядом с «Дальше» засчитывает его как верный и сразу переходит к следующему слову.
   «✎ Изменить» после ответа — правка слова прямо в тесте (слово, тайское, English, русский;
   Enter — сохранить, Esc — отмена). Сохраняется в словарь; если после правки ваш ответ
   подходит (например, дописали его как вариант перевода), он засчитывается и тест идёт дальше.
5. «Сбросить счётчики» в шапке словаря обнуляет успехи/неудачи у показанных слов
   (у всех или у слов выбранных тегов), после подтверждения.
6. Тайское написание (ไทย) — необязательное поле под словом. Показывается в словаре и
   на тренировке; в режиме «написать слово» засчитывается и транслитерация, и тайское
   написание.
7. 🔊 у слова (в словаре, на тренировке, а также в поле ไทย при добавлении и правке — по тому,
   что сейчас введено в форме) — произношение голосом Google в реальном времени. Google читает
   только тайские буквы, поэтому озвучивается тайское написание; если его нет — тайский текст
   подсказывает Gemini по транслитерации и значению (запасной вариант — Google Translate).
   Если у слова не было тайского написания, после прослушивания оно заполняется тем, что
   озвучено (в форме — в поле, у сохранённого слова — в словаре); его можно поправить.
   На диск ничего не пишется; тайский текст и mp3 держатся в памяти сервера до перезапуска.
   Звук отдаётся и по частям (Range) — без этого не играет плеер Safari/WebKit, в том числе
   в Telegram на iPhone и Mac. Нужен интернет на сервере.
   ✨ рядом с полем ไทย заполняет его с помощью Gemini — по транслитерации и переводу
   (нужен `GEMINI_API_KEY`). Результат стоит проверить; на бесплатном тарифе есть дневной
   лимит запросов, и Google может использовать запросы для обучения моделей.
8. После последнего слова или «Стоп» — статистика и список слов на повторение.
   Итоги сохраняются на сервере: у каждого слова копятся успехи/неудачи.

Настройки (направление, «Учитывать тоны») хранятся локально на устройстве.
«Учитывать тоны» по умолчанию выключено: при вводе слова `wan sao` = `wan sǎo`.

## API

| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| GET | `/api/words` | — | все слова |
| POST | `/api/words` | `{word, translation?, english?, thai?, tags?}` или массив | созданные слова (одно слово-дубль → 409, в массиве дубли пропускаются) |
| PUT | `/api/words/:id` | `{word, translation?, english?, thai?, tags?}` | слово (дубль другого слова → 409) |
| DELETE | `/api/words/:id` | — | `{ok: true}` |
| POST | `/api/reset` | `{ids: number[]}` | все слова (у этих — ok/fail обнулены) |
| POST | `/api/thai` | `{word, english?, translation?}` | `{thai}` — тайское написание от Gemini (нет ключа → 503, лимит → 429) |
| GET | `/api/tts/:id` | — | mp3 с произношением (заголовок `X-Thai-Text` — что озвучено) |
| GET | `/api/tts?word=&thai=&english=&translation=` | — | то же для несохранённого слова (по полям формы) |
| POST | `/api/results` | `[{id, success}]` | все слова с обновлённой статистикой |

`translation` — русский перевод, `english` — английский; нужен хотя бы один из них.
`thai` — тайское написание. `tags` — массив строк (хранятся в нижнем регистре).
Если в PUT нет `tags` или `thai`, они не меняются.
Устройство базы: `words` — слова, `tags` — теги (каждый один раз), `word_tags` — какие
теги у какого слова. Тег, которого не осталось ни у одного слова, удаляется сам.
Старая база при запуске обновляется сама: добавляются колонки `english` и `thai`,
теги из прежней колонки `words.tags` (JSON) переносятся в таблицы.

CORS открыт, чтобы к API могло ходить мобильное приложение.

## Структура

- `server/index.ts` — HTTP-сервер и маршруты
- `server/db.ts` — схема SQLite и запросы
- `server/tts.ts` — озвучка через Google (перевод на тайский + речь)
- `server/gemini.ts` — подсказка тайского написания через Gemini
- `server/import.ts` — замена базы загруженной при запуске (`deploy:db`)
- `scripts/deploy.ts` — деплой на Fly (секреты из `.env`, опционально база)
- `scripts/telegram-setup.ts` — настройка бота (кнопка Mini App)
- `src/telegram.ts` — запуск внутри Telegram: весь экран, цвета темы
- `server/db.test.ts` — тесты
- `src/api.ts` — клиент API
- `src/lib.ts` — типы, проверка ответа (нормализация Unicode, тоны)
- `src/SpeakButton.tsx` — кнопка 🔊
- `src/ThaiFillButton.tsx` — кнопка ✨ (тайское написание)
- `src/TagInput.tsx` — поле тегов
- `src/ToneInput.tsx` — поле ввода с таблицей гласных с тонами
- `src/Dictionary.tsx`, `src/Training.tsx`, `src/Stats.tsx` — экраны

## Деплой на Fly.io

Конфигурация — `Dockerfile` и `fly.toml` (регион `sin`, Сингапур). База SQLite лежит
на постоянном томе `/data`, поэтому машина должна быть ровно одна.

Один раз:

```bash
brew install flyctl && fly auth login
fly volumes create data --size 1 --region sin   # диск под базу
```

Каждый деплой:

```bash
bun run deploy       # код; база на сервере остаётся как есть
bun run deploy:db    # код + база на сервере заменяется локальной data.db
```

Скрипт `scripts/deploy.ts` берёт `GEMINI_API_KEY` из `.env` (образец — `.env.example`,
сам `.env` в git не попадает), кладёт его в секреты Fly и запускает
`fly deploy --ha=false` (одна машина — из-за SQLite).

С базой (`deploy:db`, то же что `deploy --with-db`):
1. делает целостный снимок локальной `data.db` (можно не останавливать локальный сервер);
2. сохраняет слова с сервера в `backups/server-<время>.json` (вернуть — «Импорт» на сайте);
3. показывает «на сервере N слов → будет M» и просит ввести «да» (`--yes` — без вопроса);
4. загружает снимок на сервер как `/data/data.db.import`; при перезапуске во время деплоя
   сервер проверяет файл и подменяет им базу, прежнюю сохраняя как
   `/data/data.db.bak-<время>` (хранятся последние 5).

Изменения, сделанные на сайте между загрузкой и перезапуском, попадут только в эту копию.

Сайт — `https://my-tutor.fly.dev`. Доступ открыт всем, кто знает адрес.
Перенести локальный словарь: «Экспорт» здесь → «Импорт» на сайте. Бэкап базы с сервера: `fly ssh sftp get /data/data.db`.

## Telegram

Словарь открывается внутри Telegram как Mini App — тот же сайт, на весь экран и в цветах
темы Telegram (`src/telegram.ts`; скрипт Telegram грузится только внутри Telegram).
Словарь общий — тот же, что на сайте.

Один раз:
1. В Telegram у @BotFather: `/newbot` → имя и username бота → токен.
2. В `.env`: `TELEGRAM_BOT_TOKEN=...` (на сервер не нужен).
3. `bun run telegram:setup` — кнопка меню «Словарик» у бота открывает `https://my-tutor.fly.dev/`
   (другой адрес — `APP_URL=...`), плюс описание бота.

## Следующий шаг: Android

Обернуть фронтенд в Capacitor; приложение ходит к этому же серверу:

```bash
bun add @capacitor/core @capacitor/android && bun add -d @capacitor/cli
bunx cap init Словарик com.example.slovarik --web-dir dist
PUBLIC_API_URL=http://<IP-компьютера>:3000 bun run build
bunx cap add android && bunx cap sync && bunx cap open android
```

Для HTTP (не HTTPS) в Android нужно разрешить cleartext-трафик
(`android:usesCleartextTraffic="true"` или `server.cleartext` в capacitor.config).
